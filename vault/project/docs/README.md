# Project docs

Diagrams, user flows, review reports, presentations and any other project document that is not
a feature doc, an ADR, a plan or the spec. One file per document, kebab-case, under 50 characters
(`user-flow.md`, `deploy-review-2026-09.md`). Link it from the spec, the feature doc or the plan
that needs it; `/vault project:` writes here by default.
